# 성분/제형 2층 디스크립터 설계안

대상: 눈 자극·손상(GHS 3.3) / 피부 부식·자극(3.2) / 피부 감작(3.4) 예측
근거 문서: `현 연구의 모델 개발 방향 및 데이터 수집에 관한 종합적 고찰.docx` (Track A 직접예측 / Track B GHS-CT 잔차보정)
구현: `work/lib_desc.py`, `work/build_input_v2.py` → `input_dataset_v2.xlsx`, `out/v2/*`

---

## 0. 왜 2층인가 — 설계의 출발점

제형 독성은 "성분들의 성질"과 "성분들이 섞여서 생기는 성질"의 합. 이 둘을 한 층으로
합치면 두 가지 문제가 발생한다.

1. **해석 불가.** 모델 출력이 "logP가 높아서"일 때, 그것이 *어떤 성분의* logP인지
   알 수 없으면 제형 설계에 활용 불가.
2. **GHS-CT 와 접점 소실.** CT 가산식은 정의상 `Σ(성분 구분 × 성분 농도)`.
   성분 단위 표현이 없으면 Track B 구성 자체가 불가.

구조는 다음과 같이 구성.

```
[성분 블록]  성분 1개 = 1행                     [제형 블록]  제형 1개 = 1행
 구조 디스크립터 · 지문 · 역할 · 전하클래스   →  ① 농도가중 모멘트 (가산 성분)
 성분 자신의 GHS 구분 · 함량                  →  ② 상호작용 항   (비가산 성분)
                                              →  ③ 제형 실측 물성 (pH·점도·상태…)
                                              →  ④ CT baseline 블록 (Track B 입력)
```

산출 파일 대응:
- 성분 블록 → `out/v2/X_ingredient.parquet` (5,287 × 174), `fp_ing_{morgan,maccs}.npz`
- 제형 블록 → `out/v2/X_formulation.parquet` (1,675 × 518 = 피처 517 + ID), `fp_form_pooled.npz`

## 1. 성분 블록 (per-ingredient)

### 1.1 구조 디스크립터 — 기전 대응 기준 선정

디스크립터를 일괄 대량 투입하는 방식은 채택하지 않음. 눈/피부 자극의 알려진 기전 축마다
대표 디스크립터를 배치.

| 기전 축 | 디스크립터 | 왜 |
|---|---|---|
| 각질층/눈물막 투과 | `MolWt`, `TPSA`, `LabuteASA`, `HeavyAtomCount` | MW 500 이상은 각질층 통과가 급감. 표면적은 접촉면적의 대리지표 |
| 소수성 분배 | `MolLogP`, `MolMR` | 지질이중층 분배계수. 자극의 1차 결정인자 |
| 단백질 변성 성향 | `NumHDonors`, `NumHAcceptors`, `NOCount`, `NHOHCount` | 수소결합 공여/수용 능력이 각막 단백질 3차구조를 흐트러뜨림 |
| 분자 유연성/형태 | `NumRotatableBonds`, `FractionCSP3`, `Kappa1~3`, `HallKierAlpha` | 유연한 사슬은 막에 끼어들기 쉬움 |
| 방향족성/평면성 | `NumAromaticRings`, `RingCount`, `BertzCT` | 스태킹·삽입(intercalation) 성향 |
| 친전자성 (감작성) | `MaxPartialCharge`, `MinPartialCharge`, `MaxAbsPartialCharge` | 단백질 친핵부(Lys/Cys)와의 공유결합 부가체 형성 경향 |

### 1.2 구조경보 (structural alerts) — 감작성의 핵심

OECD 피부감작 AOP 의 Key Event 1(단백질 공유결합)에 해당하는 반응성 부분구조를
SMARTS 로 직접 계수. 감작성은 연속형 물성보다 "이 반응기가 있는가"가 훨씬 강한 신호.

```
michael_acceptor  aldehyde  epoxide  isothiocyanate  acyl_halide
quinone  nitro_aromatic  anhydride  sulfonyl_halide  thiol
→ n_structural_alerts (합계) + has_* (개별 플래그)
```

### 1.3 계면활성제 전하 클래스 — 제형 독성의 최대 단일 요인

농약/생활화학제품에서 눈·피부 자극의 실질적 주요 요인은 유효성분이 아니라 계면활성제인
경우가 많다. 따라서 별도 축으로 분리.

- 구조 기반: `long_alkyl`(C8+ 사슬) **AND** 머리기 → `anionic` / `cationic` / `nonionic`(폴리에톡실레이트) / `amphoteric`(베타인)
- 구조가 없으면 이름 규칙으로 보완 (`surf_class_src` = `structure` | `name_rule`)
- 보조: `max_alkyl_chain`(소수부 크기), `n_pos_atoms`/`n_neg_atoms`/`is_ionic`

전하 분류를 별도로 나누는 이유는 §2.2 의 전하쌍 상호작용.

### 1.4 도메인 파생

- **`logKp_pottsguy`** = `-2.7 + 0.71·logKow - 0.0061·MW` — 피부 투과계수 추정.
  MW 와 logP 의 **비선형 결합**을 미리 계산해 투입함으로써, 트리 모델이 곱셈항을
  근사하는 데 소모하는 분기를 줄인다.
- **`has_metal`, `n_fragments`** — 금속염·복합염 식별 (RDKit 디스크립터가 무의미해지는 구간의 게이트)
- **`ing_role_final`** — active_presumed / surfactant / solvent / synergist / carrier_inert /
  propellant / ph_adjuster / preservative / thickener / fragrance_dye / water
- **`ing_pct_rank`, `ing_is_max_pct`** — 조성 내 서열

### 1.5 지문 (fingerprint)

- **Morgan/ECFP4 2048bit** — 국소 환경 기반. 유사 화합물 검색·활성절벽 탐지에 강함
- **MACCS 167bit** — 해석가능한 사전정의 키. docx 가 인용한 선행연구에서 MACCS+SMOTE 가
  최고 F1 을 낸 조합이므로 비교군으로 유지 필요

두 지문은 `.npz` 로 별도 저장(`fp_ing_morgan.npz`, `fp_ing_maccs.npz`).
행 순서 = `ingredient` 시트 행 순서, `has_structure` 마스크 동봉.

### 1.6 성분 자신의 GHS 구분 ⚠️

`ing_ghs_eye` / `ing_ghs_skin` / `ing_ghs_sens` + `ing_ghs_src`.

**원본 `input_dataset.xlsx` 의 `ghs_*`/`cat_*` 컬럼을 성분 피처로 사용 금지.** 해당 값은
제형 라벨을 성분 행에 브로드캐스트한 값이므로(제형별 성분간 distinct 조합 = 1), 성분
피처로 사용하는 순간 타깃을 그대로 복사해 넣는 완전 누출에 해당. 이번 패스에서 Phase 1
에이전트가 PubChem PUG-View / ECHA C&L 로 실제 성분 단위 분류를 회수한 **1,174행**만
`ing_ghs_*` 에 포함(직접 확인 159 · 동일 CAS 전역 재사용 871 · 이름 매칭 144).

## 2. 제형 블록 (per-formulation)

### 2.1 ① 농도가중 모멘트 — 가산 성분

성분 블록의 19개 핵심 디스크립터마다 6종 집계:

```
f_<D>_wmean   농도가중 평균  ← 가산성 가정과 정합. 기본 피처
f_<D>_mean    단순 평균      ← 농도 결측 대비 폴백
f_<D>_max     최댓값        ← "가장 독한 성분이 지배한다"는 임계 거동
f_<D>_min     최솟값
f_<D>_range   max-min       ← 조성의 이질성
f_<D>_std     표준편차       ← 분산 자체가 상호작용 잠재력
```

`max` 를 함께 투입하는 이유: 자극은 평균이 아니라 **최악 성분**이 결정하는 경우가 많음.
`std`/`range` 를 투입하는 이유: 성질이 크게 다른 성분이 혼합되면(친수+친유) 가용화·침투촉진이
일어나기 쉬우므로, 분산 자체가 비가산성의 예측인자.

조성 다양성: `f_shannon`, `f_simpson`, `f_max_pct` — 단일물질(엔트로피 0)과 복합제형을 구분.

### 2.2 ② 상호작용 항 — 비가산 성분 (설계의 핵심)

docx §상호작용이 인용한 60개 이성분 혼합물 연구는 48% 가산 / 40% 길항 / 12% 시너지.
즉 **절반 이상이 비가산**. 가산 항(=§2.1)만으로는 이 절반을 설명할 수 없으므로,
알려진 비가산 기전마다 명시적 곱셈항을 구성해 투입.

| 피처 | 기전 |
|---|---|
| `f_surf_charge_pair` = %anionic × %cationic | 음이온·양이온 계면활성제가 이온쌍(catanionic complex)을 이뤄 침전/단량체 활성 소실 → **길항**. SDS+C12TAB 의 고전적 사례 |
| `f_surf_anionic_nonionic` = %anionic × %nonionic | 혼합미셀 형성 → CMC 하강 → 저농도에서 단량체 농도 증가 → **저농도 시너지** |
| `f_surf_charge_imbalance` = (A−C)/(A+C) | 전하 균형점 근처에서 상호작용이 최대. 부호 있는 비대칭도 |
| `f_solvent_x_logp` = %solvent × logP_wmean | 유기용매가 각질층 지질을 추출해 유효성분 침투를 증폭 (POEA/글리포세이트형) |
| `f_surf_x_logkp` = %surf_total × logKp_wmean | 계면활성제로 장벽이 깨진 상태에서의 투과 — 곱셈 구조 |
| `f_has_synergist` | 피페로닐부톡사이드 등 P450 억제제. 대사적 해독을 차단해 다른 성분의 실효 독성을 상승시킴 |
| `f_tanimoto_{mean,max,min}` | 성분간 구조 유사도. 유사성분 조합(≈가산)과 이질조합(≈비가산)의 구분 |
| `f_pct_surf_total`, `f_pct_{role}` | 역할별 총 농도 (11종) |

**추가로 넣으면 좋을 것 (아직 미구현, 데이터 필요):**
- `%acid × %base` — 중화열/발열 반응
- 성분 pKa 분산 × pH — 이온화 상태가 침투를 지배하는 구간
- 성분쌍 logP 차이의 최댓값 — 가용화 잠재력의 직접 표현
- 저농도/고농도 반전을 표현하려면 **농도별 반응곡선**이 필요(현 데이터에 없음 → §후속작업)

### 2.3 ③ 제형 실측 물성 — 구조에서 나오지 않는 정보

2차 배정 특성 시트로 새로 확보한 블록. **input_dataset v1 에는 미포함 항목.**

`pc2_ph`(533) · `pc2_mp`(786) · `pc2_bp`(382) · `pc2_fp`(430) · `pc2_vp`(691) ·
`pc2_density`(723) · `pc2_solubility`(607) · `pc2_logkow`(666) · `pc2_viscosity`(158) ·
`pc2_physical_state`(886, one-hot) · `pc2_solubility_qual`

이 중 **pH 의 기여가 가장 큼.** 단일 피처로서도 강하지만(pH 2 미만/11.5 초과는 기전
자체가 화학적 부식으로 바뀜), 그보다 **CT 가산식의 적용 가능성 게이트**라는 점이 결정적:

```
ph_strong_acid  (pH ≤ 2)    4 제형
ph_strong_base  (pH ≥ 11.5) 8 제형
ct_not_applicable = 강산 ∨ 강염기 ∨ 계면활성제 ≥ 20%    23 제형
```

제형코드(CIPAC)도 이 블록에 포함 — `form_code_best` one-hot. EC/SL/WG/SC 같은 코드는
사실상 "물리적 형태 + 용매계 + 계면활성제 존재"를 한 토큰으로 압축한 전문가 지식.

### 2.4 ④ CT baseline 블록 — Track B 의 입력과 타깃

`ct_predict()` 가 GHS 개정판 3.2.3(피부) / 3.3.3(눈) / 3.4.3(감작) 표를 그대로 구현.

```
눈   : ΣCat1 ≥ 3%  → 1 · 1%≤ΣCat1<3% → 2 · ΣCat2 ≥ 10% → 2 · 10ΣCat1+ΣCat2 ≥ 10% → 2
피부 : ΣCat1 ≥ 5%  → 1 · 1%≤ΣCat1<5% → 2 · ΣCat2 ≥ 10% → 2 · 10ΣCat1+ΣCat2 ≥ 10% → 2 · ΣCat3 ≥ 20% → 3
감작 : ΣCat1 ≥ 1.0% → 1 · Cat1A 성분 ≥ 0.1% → 1
```

산출 피처 (엔드포인트별): `f_ct_{ep}_cat`(예측구분) · `f_ct_{ep}_ord`(순서형) ·
`f_ct_{ep}_s1`(ΣCat1) · `f_ct_{ep}_s2`(ΣCat2) · `f_ct_{ep}_add`(10s1+s2) ·
`f_ct_{ep}_n_known` · `f_ct_{ep}_coverage`

CT baseline 이 산출된 제형: **눈 719 · 피부 719 · 감작 721** / 1,675.

**Track B 타깃**: `resid_{ep}` = `y_{ep}_ord` − `ct_{ep}_ord`
현재 정의 가능한 행(= 라벨 ∩ CT): **눈 456 · 피부 382 · 감작 184.**

Track B 를 이러한 형태로 구성하는 근거는 docx 의 논지와 동일 — 가산 항은 이미 CT 가
설명하므로, **잔차 모델의 입력은 상호작용 항(§2.2)과 예외 게이트(§2.3)로 한정할 것**.
가산 항을 다시 투입하면 모델이 CT 를 재학습하는 데 표본 효율이 떨어진다.

실측 잔차 분포는 다음과 같다:

| 엔드포인트 | n | CT 정확(resid=0) | CT 과소예측(+) | CT 과대예측(−) |
|---|---|---|---|---|
| 눈 | 456 | 190 (42%) | **213 (47%)** | 53 (12%) |
| 피부 | 382 | 260 (68%) | 94 (25%) | 28 (7%) |
| 감작 | 184 | 113 (61%) | 61 (33%) | 10 (5%) |

→ **CT 는 체계적으로 과소예측(under-call)하는 경향.** 눈에서는 절반 가까이(213/456)가
실제보다 낮게 산출되고, 피부는 CT 가 2/3 를 적중. 이 비대칭이 "상호작용을 반영하지 않은
결과"에 해당하는 잔차이며, Track B 가 포착해야 할 신호.

감작성은 F0.5 이전 과대예측이 **0건**이었으나 음성표본 확보 후 10건 발생. 즉
감작 Track B 는 "CT 가 놓친 양성을 찾는" 사실상의 이진 과제에서 3클래스 과제로
전환되었으나, 소수클래스가 10건뿐이므로 **현 시점에서 감작 Track B 성능은 보고 불가**
(`LIMITATIONS.md` §L2 항목 4).

### 2.5 제형 단위 지문 pooling

성분 지문을 제형 단위로 집계하는 방법은 두 가지가 필요.

```
max-pool    : "이 부분구조가 조성 안에 존재하는가"  (존재 여부)
농도가중 mean: "얼마나 많이 존재하는가"             (양)
```

둘은 서로 다른 정보 — 0.1% 향료에 포함된 알데히드와 30% 주성분의 알데히드는 max 로는 동일,
wmean 으로는 상이. `fp_form_pooled.npz` 에 `morgan=[max|wmean]`(4096), `maccs=[max|wmean]`(334)로
연결해 저장.

## 3. 누출 차단 설계 (반드시 지킬 것)

### 3.1 라벨 유도 컬럼은 피처에서 제외

`y_eye`/`y_skin` 중 상당수(`y_*_src == sds_v1` 181/157, `sds_2nd` 135/123,
`sds_2nd_sec11` 150/137, `phase1_sds` 31/31)는 **SDS 의 H코드·서술문에서 유도된 라벨**.
따라서 `tox_h_statements`, `tox_signal_word`, `tox2_h_codes`, `t11_*_cat`/`t11_*_raw`/`t11_pic_*`,
`ghs_*`, `sds_ghs_*`, `ntp_*_cat` 계열은 전부 `role=label_source` 로 표시해 X 행렬에서
물리적으로 제외. `out/v2/feature_manifest.csv` 의 `role` 컬럼이 정본이며, **228열**이
label_source 로 분류됨. 스모크 테스트에서 X ∩ label_source = **0** 확인.

추가로 F0.5(§L11)에서 유입된 열 중 **라벨과 같은 SDS 문서에서 유래한 54열**

## 4. 학습 레시피 권고

### Track A — 직접예측

1. **입력**: `X_formulation.parquet` + `fp_form_pooled.npz`(MACCS max/wmean 우선)
2. **불균형 대응**: docx 가 정리한 대로 `class_weight='balanced'` → SMOTE → SMOTEENN
   순으로 비교. **단, 리샘플링은 CV 폴드 내부에서만** 적용(폴드 밖에서 하면 누출).
3. **순서형 구조 활용**: `y_*_ord` 로 ordinal regression 또는 누적 이진분류
   (`P(≥2B)`, `P(≥2A)`, `P(=1)`)를 적층하는 방식이 다중분류보다 우세할 가능성이 높음.
4. **임계값 튜닝**: F1/Youden J 기준으로 폴드별 최적화. 기본 0.5 는 불균형에서 무의미.

### Track B — CT 잔차보정

1. **입력**: §2.2 상호작용 항 + §2.3 예외 게이트 + CT 합계(`f_ct_*_s1/s2/add`)
   — 가산 항(§2.1 모멘트)은 **투입 금지**
2. **타깃**: `resid_{ep}` (회귀) 또는 `sign(resid)` 3클래스 (과소/정확/과대)
3. **최종 예측**: `ct_ord + 예측잔차` 를 반올림·클리핑
4. **해석**: SHAP 으로 "어떤 상호작용이 CT 오차에 얼마나 기여했는가"를 직접 확인.
   이것이 Track B 의 주 산출물 — 성능보다 기전 가설

### 앙상블

`ct_*_coverage` 로 게이팅. CT 커버리지가 높은 행은 Track B 가중을 상향하고,
구조는 있으나 성분 GHS 가 없는 행은 Track A 로 이관. 단순 평균보다
**커버리지 기반 라우팅**이 이 데이터의 결측 구조에 적합.
