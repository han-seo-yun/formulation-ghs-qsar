## 2. 실행 (순서 중요)

```bash
cd "$BASE"
python3 work/verify_sheets.py       # ① 검증란 채움 → dataset_2차배정_verified.xlsx
python3 work/build_input_v2.py      # ② 모델 입력 전체 생성 (out/v2/ + input_dataset_v2.xlsx)
python3 work/smoke_baseline.py      # ③ 누출·그룹분할 점검 + 베이스라인
```

- ①은 이미 만들어진 verified 파일이 있으면 **건너뛸 수 있음**(②의 입력이 그 파일).
- ②는 **멱등**. 여러 번 돌려도 같은 결과가 나옴. 5~10분 정도(RDKit 디스크립터 계산).
- ②는 `dataset_2차배정.xlsx` / `input_dataset.xlsx` **원본을 절대 수정하지 않음.**

## 4. 파일 역할

| 파일 | 하는 일 |
|---|---|
| `build_input_v2.py` | **메인 빌더.** 11단계. v1 병합 → 2차 시트 파싱 → SDS §11 재파싱(F0.5) → 디스크립터 → 집계 → CT → 라벨 통합 → 누출 분류 → 저장 |
| `lib_parse.py` | 시트 `추출정보` 자유서술 파싱 4종(성분/제형/독성/물성) + **GHS CT 가산식 `ct_predict()`** |
| `lib_desc.py` | SMILES → RDKit 디스크립터 31종 · Morgan/MACCS 지문 · 구조경보 24종 · 역할 추정 · 계면활성제 전하 분류 |
| `lib_tox11.py` | SDS Section 11 서술문 → `t11_*`. **파싱 규칙 5원칙이 이 파일 docstring 에 정본으로 있다** |
| `verify_sheets.py` | 4시트 `검증여부` 규칙 엔진 + `검증근거`·`검증방식` 열 추가. 병합셀 해제·드롭다운 재구성 |
| `smoke_baseline.py` | 누출 점검 + `StratifiedGroupKFold` 베이스라인 + 더미 비교 |
| `MASTERPLAN.md` | 이번 패스의 작업 계획·이력 (WebSearch 미제공 등 환경 제약 기록 포함) |

## 5. 라벨 우선순위 (수정 지점)

`build_input_v2.py` 의 라벨 통합 단계에 티어가 순서대로 정의돼 있음. **위가 우선.**

```
1. ntp_measured      NTP 실측 (눈 608 · 피부 544)
2. sds_v1            v1 SDS H코드 (181 / 157)
3. sds_2nd           2차 수집 H코드·신호어 (135 / 123 / 감작 198)
4. phase1_sds        Phase 1 에이전트 회수 (31 / 31 / 29)
5. sds_2nd_sec11     ★ F0.5 — Section 11 서술문 (150 / 137 / 184)
```

5번을 **가장 낮은 우선순위**에 둔 이유: 정규식으로 파싱한 자유서술이라 상위 티어의
기존 라벨을 덮으면 안 됨. 즉 **신규 라벨만 추가되고 기존 값은 불변**.

새 출처를 추가할 때도 같은 원칙으로 맨 아래에 붙이고, `y_*_src` 로 추적 가능하게 함.
