## 2. 최소 로딩 코드

```python
import pandas as pd, numpy as np
from sklearn.model_selection import StratifiedGroupKFold
from sklearn.ensemble import RandomForestClassifier

X = pd.read_parquet("X_formulation.parquet")
Y = pd.read_parquet("y_formulation.parquet")
G = pd.read_parquet("groups.parquet")

FEATS = [c for c in X.columns if c != "Formulation_ID"]
D = X.merge(Y, on="Formulation_ID", suffixes=("", "__y")).merge(G, on="Formulation_ID")
#                                  ↑ 필수. X 와 Y 에 ct_*_ord 가 둘 다 있어 이름이 깨진다

m = D["y_eye_ord"].notna()                       # 눈 순서형 타깃 보유 행
cv = StratifiedGroupKFold(5, shuffle=True, random_state=0)
for tr, te in cv.split(D.loc[m, FEATS], D.loc[m, "y_eye_ord"], groups=D.loc[m, "group_key"]):
    clf = RandomForestClassifier(300, class_weight="balanced", n_jobs=-1, random_state=0)
    clf.fit(D.loc[m, FEATS].iloc[tr].fillna(-999), D.loc[m, "y_eye_ord"].iloc[tr])
    ...
```

## 3. 타깃 정리

| 컬럼 | 내용 |

| `y_*_src` | 라벨 출처. `ntp_measured`(실측) > `sds_v1` > `sds_2nd` > `sds_2nd_sec11` > `phase1_sds` |

## 4. ⚠️ 금지사항

### 4.1 `label_source` 228열은 피처가 아님

```python
MAN = pd.read_csv("feature_manifest.csv")
banned = set(MAN.loc[MAN.role == "label_source", "column"])
assert not (set(FEATS) & banned)      # X_*.parquet 에는 이미 없다 — 통과해야 정상
```

`tox_h_statements`, `tox_signal_word`, `ghs_*`, `ntp_*_cat`, `t11_*_cat`, `t11_*_raw`,
`t11_pic_*` 등이 여기 속함. 라벨을 유도한 원본이므로 넣으면 완전 누출에 해당.

### 4.2 `sds_coderived` 54열은 써도 되지만 ablation 필수

```python
co = set(MAN.loc[MAN.sds_coderived == True, "column"])   # t11_ld50_*, t11_acute_*_ord 등
```

라벨과 **같은 SDS 문서**에서 나온 피처. 누출은 아니지만 동일문서 상관이 있을 수 있어
**논문에는 이 열을 뺀 결과를 함께 보고**함. 실측 ablation 결과는
`04_문서/LIMITATIONS.md` §L2.1 (결론: 성능 기여 거의 없음 — 이번 이득은 라벨에서 옴).

### 4.3 단순 KFold 금지

`groups.parquet` 의 `group_key` 없이 분할하면 같은 활성성분 제형이 train/test 로 갈려
성능이 과대평가됨. 최대 그룹은 46행.

### 4.4 리샘플링은 폴드 내부에서만

SMOTE/SMOTEENN 을 CV 밖에서 적용하면 누출에 해당.

## 5. 현재 베이스라인 (RF, 튜닝 전 · 지문 미포함 = 하한선)

| 과제 | n | F1 | balAcc | 더미 |
|---|---|---|---|---|
| 눈 순서형 | 1,105 | 0.499 | 0.496 | 0.128 |
| 피부 순서형 | 992 | 0.507 | 0.494 | 0.191 |
| 감작 순서형 | 595 | 0.677 | 0.670 | 0.393 |
| 눈 이진 | 1,105 | 0.798 | 0.624 | 0.793 |
| 피부 이진 | 992 | 0.679 | 0.752 | 0.000 |
| 감작 이진 | 595 | 0.808 | 0.670 | 0.787 |
| Track B 눈 / 피부 | 456 / 382 | 0.628 / 0.618 | — | ~0.33 |
| Track B 감작 | 184 | 0.417 | — | ~0.33 |

**해석 주의 3가지**
1. **F1 절대값으로 비교하지 말 것.** 음성 라벨이 늘면 F1 은 내려가고 문제의 난이도가 정상화됨.
   눈 이진은 F1 0.832→0.798 로 "떨어졌지만" 더미가 0.838→0.793 으로 더 떨어지고
   balAcc 은 0.593→0.624 로 오름.
2. **순서형 점수는 ±0.03 흔들림.** 5-fold 1회로는 개선인지 노이즈인지 구분이 어려움.
   **5×5 repeated 로 바꾸는 것이 최우선 작업.**
3. **감작 Track B 0.417 은 보고하지 않음** — 클래스 2→3개 전환 인공물(소수 클래스 10행).

## 6. 권장 다음 단계 (효과 큰 순서)

1. **5×5 repeated StratifiedGroupKFold** 로 전환 — 이걸 먼저 안 하면 나머지 실험 해석 불가.
2. **순서형을 누적 이진분류로** (`P(≥2B)`, `P(≥2A)`, `P(=1)` 스택). 이진 F1 이 더미를
   0.005 차이로 겨우 넘는 상황에서 개선 효과가 가장 확실한 항목.
3. **지문 투입** — `fp_form_pooled.npz` 의 MACCS 먼저(해석 가능·선행연구 비교군), Morgan 은 다음.
4. **불균형 대응** — `class_weight='balanced'` → SMOTE → SMOTEENN 순 비교 (폴드 내부에서만).
5. **Track B SHAP** — 성능보다 "어떤 상호작용이 GHS 가산식을 얼마나 틀리게 하는가"가
   이 연구의 실질적 산출물에 해당. 계면활성제 전하쌍·용매×logP 항이 잡히는지 확인.

상세 레시피는 `04_문서/DESCRIPTOR_DESIGN.md` §4.
