## 3. 요약

- 제형 1,675건 중 **1,525건에 정답 부착** — 눈 1,105 · 피부 992 · 감작 595.
- 이번 주 최대 성과는 **음성("자극 없음") 라벨 확보**. 감작 양성률 87.8% → **64.9%**.
- 핵심 가설 유효: **GHS 농도가산식이 언제 틀리는지 예측 가능**(0.62 vs 우연 0.33),
  그리고 가산식은 눈에서 **47%를 과소평가**.
- 병목은 모델이 아니라 데이터: ① pH 결측(제품값 여부 미분리 포함) ② 감작성 실측값 0건
  ③ **성분 GHS 구분 결측** — 함량은 2,769행 확보돼 있고, 함량은 있는데 성분 GHS 가 없는
  성분 행이 1,963개. CT 산출률의 실제 병목은 함량이 아니라 성분 GHS 구분.

⚠️ **성능은 F1 만 보면 거꾸로 읽힘.** 눈 이진 F1 이 0.832 → 0.798 로 하락했으나,
같은 구간에 무작위 더미가 0.838 → 0.793 으로 더 크게 하락하고 balAcc 은 0.593 → 0.624 로
상승. 모델 성능 저하가 아니라 과제 난이도가 정상화된 결과.
**반드시 "더미 대비 + balAcc" 로 함께 판단.**

## 4. 절대 하면 안 되는 것 3가지

1. **`input_dataset_v2.xlsx` 를 모델에 직접 투입 금지.**
   정답을 유도한 컬럼 **228개** 포함(누출). `02_모델입력_데이터/*.parquet` 에는
   이미 제외돼 있음. 판단 기준은 `feature_manifest.csv` 의 `role == "label_source"`.
2. **`groups.parquet` 없이 CV 금지.**
   같은 활성성분을 쓰는 제형이 train/test 로 갈리면 성능 과대평가 발생.
   **664 그룹**으로 `StratifiedGroupKFold` 사용.
3. **감작 Track B 점수(0.417) 보고 금지.**
   클래스 수가 2→3개로 바뀐 인공물(소수 클래스 10행). n≥30 이 될 때까지 비공개.
