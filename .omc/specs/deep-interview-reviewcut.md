## 3. 판독 결과 기록 규칙 (사용자 승인 사항 = "신뢰도 분기")

### 성분 시트 — 함량 판독

| 등급 | 판정 조건 (전부 충족) | 기록 |
|---|---|---|
| **HIGH** | ① 문서 Section 3에 행의 CAS가 **정확히 일치**하여 등장 ② 같은 줄에 **수치 함량**(단일값·범위) 존재 ③ 그 CAS가 문서 내 **1회만** 등장 | `검증완료` 자동 기입 |
| **HIGH-NEG** | 문서 Section 3에 성분은 있으나 함량을 문서가 **비공개**(Proprietary / Trade secret / 공란)로 명시 | `정보없음` 자동 기입 (근거: 문서 확인, 함량 비공개) |
| **MEDIUM** | CAS 불일치·성분명만 일치 / 함량이 비수치(`<`, `≤`, `balance`, `기타`) / 동일 CAS 다중 등장 | `자동판독_사람확인대기` (신설 상태) |
| **LOW** | 문서에 CAS·성분명 모두 없음 → 문서가 다른 제품일 가능성 | `자동판독_사람확인대기` + `제외` 제안 플래그 |
| **FAIL** | fetch 실패 / PDF 파싱 실패 | `재검토필요` **유지**, 검증근거의 사유만 정정 |

### 독성코드 시트 — 자동 승급 금지

독성코드는 **라벨(y)에 직결**된다. 성분 참고값 40행이 이미 라벨을 오염시킨 전례가 있으므로:

> 독성코드 판독 결과는 등급과 무관하게 **전부 `자동판독_사람확인대기`** 로만 기록한다. 자동 `검증완료` 없음.

### 감사 추적 (모든 등급 공통, 신설 컬럼)

`판독_문서경로` · `판독_페이지` · `판독_추출원문`(스니펫 원문 그대로) · `판독_등급` · `판독_규칙버전`

→ 오류가 발견되면 자동 승급분을 **전량 롤백 가능**하게 한다.

### 자동 승급 사후 검수 게이트

HIGH 자동 승급분에서 무작위 **30행**을 사람 검수 워크리스트에 올린다. 오류율 **>5%** 이면 자동 승급 전량 롤백 후 규칙 재설계.

```python
def cas_ok(s):
    s = str(s).strip()
    if not re.fullmatch(r"\d{2,7}-\d{2}-\d", s): return None   # 형식 자체가 CAS 아님 = 결측
    a, b, c = s.split("-")
    digits = (a + b)[::-1]
    return sum(int(d) * (i + 1) for i, d in enumerate(digits)) % 10 == int(c)
```
